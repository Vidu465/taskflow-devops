## Commands I learned:

[sudo]          → Run commands with administrator (root) permission.
[echo]          → Print text or write text into a file.
[>]             → Redirect output to a file (creates/overwrites).
[>>]            → Add new content to the end of a file.
[cat]           → View file contents.
[mkdir]         → Create a new folder.
[grep]          → Search for text inside files.
[grep] -r       → Search inside folders and subfolders.
[grep] -i       → Ignore uppercase/lowercase differences.
[grep] -l       → Show only file names containing the text.
[grep] -s       → Hide error messages.
[2>]            → Redirect error messages into a file.
[2>&1]          → Send errors and normal output to the same file.
[python3]       → Run Python scripts.
[zcat]          → Read .gz compressed files without extracting.
[gunzip]        → Extract .gz compressed files.
[|]             → Pipe output from one command to another.
[tee]           → Show output on screen and save it to a file.
[cd]            → Move between directories.
[/mnt]          → Access Windows drives in WSL (C:\ → /mnt/c, D:\ → /mnt/d).
